# 大件货品智能配载平台 · 使用说明

> 版本：v5.2 ｜ 形态：纯前端 Web 应用（单文件 HTML，双击即用，零安装零后端）
> 适用对象：仓配调度员、装载规划员、司机、运营管理人员

---

## 1. 平台简介

本平台解决大件货品（家电、家具、托盘货、设备箱等）装车前的**三维配载决策**问题。输入车队与货物清单，输出可直接执行的三维装载方案、装卸顺序单与合规报告。

核心能力一览：

| 能力 | 说明 |
|---|---|
| 三维装箱求解 | Guillotine 空间分割 + BLB 放置 + 四种排序策略竞争择优，毫秒级出方案 |
| 多车自动分配 | 混编车队按温层、站点归属自动分车，装不下的自动溢出到下一辆 |
| 堆叠承重校验 | 每件货品可设承重上限，压力沿支撑链向下累计传递（C压B压A 时 A 校验 B+C 之和） |
| 温层隔离 | 冷冻/冷藏/常温三层，货品温层与车厢温区不符自动拒装 |
| 站点顺序装车 | 联动配送路线：先到站的货靠车门、后到站的装深处，减少卸货翻箱 |
| 装卸顺序单 | 自动推演"后装先卸 + 上层先卸 + 按站点顺序"的完整作业序列 |
| 3D 可视化 | 车厢线框 + 货品实体渲染，旋转缩放查看，点击货品查详情 |
| 工单与报告 | 装卸工单（司机任务单）打印、装载合规校验报告（重心/偏载） |

## 2. 快速上手（3 分钟）

**第 1 步：打开应用**
双击 `冷链智能物流调度_配载版.html`（单文件版），浏览器自动打开。页面已预载示例车队（2 辆 4.2 米厢式货车）与示例货物（6 类 18 件）。

**第 2 步：一键体验**
点击左侧醒目的 **「🧊 一键智能配载」** 按钮。数秒后右侧出现：
- 顶部 6 项指标（已装件数、体积利用率、重量利用率、层数、用车数、未装数）
- 车辆切换卡片，点击可在多车间切换查看
- 3D 装载视图

**第 3 步：查看装卸顺序**
点击结果区右上角 **「🔢 装卸顺序」** 标签页，左侧为装车顺序（从车厢深处到门口），右侧为卸货顺序（后装先卸）。点击 **「🖨️ 装卸工单」** 可直接打印给司机。

想零配置看全链路演示，直接点左上角 **「🚀 调度 → 配载 → 工单」** 一键全流程按钮即可。

## 4. 功能详解

### 4.1 一键全流程（调度 → 配载 → 工单）

自动串起完整链路，适合演示或快速生成全套方案：

1. **规划配送路线**：用内置需求数据执行 VRP 求解
2. **路线站点匹配货物**：为每个站点生成随机尺寸的大件货品
3. **多车配载求解**：按路线站点顺序装车
4. **生成工单与报告**：装卸工单、合规报告就绪可打印

三个可调参数：

| 参数 | 范围 | 默认 | 说明 |
|---|---|---|---|
| 调度网点数上限 | 5~206 | 30 | 参与路线规划的配送点数量 |
| 求解时限(秒) | 3~120 | 20 | VRP 求解时间预算 |
| 每站点货品数 | 1~20 | 3 | 每个站点生成的货品件数 |

> 全流程生成的货物是随机示例，加载自己的货物后可手动替换，再点「一键智能配载」重算。

### 4.2 车队配置

- **添加车辆**：点击「＋ 添加车辆」，默认 4.2 米厢式货车（420×210×210cm、载重 3000kg）
- **车辆参数**：名称、长 L / 宽 W / 高 H（cm）、载重（kg），均可编辑
- **数量**：同型号车辆填数量即可批量展开（如数量 3 = 3 辆同规格车）
- **温区勾选**：每辆车可勾选 冷冻-18℃ / 冷藏2~8℃ / 常温，温层不符的货品会被该车拒装
- **删除**：卡片右上角 ✕

支持多种车型混编（如 4.2 米 + 6.8 米 + 冷藏车），货品自动分配到最合适的车。

### 4.3 货物清单

货物表格每行一类货品，字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| 名称 | ✅ | 货品名（如"对开门冰箱"） |
| 长/宽/高 cm | ✅ | 外包装尺寸（含自身包装） |
| 重量 kg | — | 单件重量 |
| 数量 | ✅ | 同规格件数，展开后逐件装箱 |
| 可旋转 | — | 勾选=允许 6 向旋转；不勾=保持原方向（冰箱/空调等不可倒置件务必不勾） |
| **承重 kg** | — | **该货品顶面可承受的总重量**。留空=不限。见 §5.2 承重链 |
| 配送站点 | — | 目的站点名，须与路线站点名一致才触发按站装车 |
| 温层 | — | 🧊冷冻 / ❄️冷藏 / ☀️常温 |

**数据录入方式（5 种）**：
1. **手动添加**：「＋ 添加货品」逐行填写
2. **载入示例**：「📂 载入示例货物」一键载入 6 类典型大件
3. **导入 Excel**：「📥 导入 Excel」，识别列名见下方模板
4. **读取调度结果**：「📡 读取调度结果」直接读取「智能调度」页保存的配送路线（同浏览器共享，免导出 JSON）
5. **导入配送路线**：「🗺️ 导入配送路线」导入调度模块导出的路线 JSON 文件

**Excel 导入模板**（首行表头，列名支持别名）：

| 名称* | 长cm* | 宽cm* | 高cm* | 重量kg | 数量 | 可旋转 | 承重kg | 类型 |
|---|---|---|---|---|---|---|---|---|
| 对开门冰箱 | 90 | 75 | 190 | 95 | 2 | 否 | 300 | 家电 |

> 别名支持：货品名称/品名 → 名称；长/宽/高 → 长cm/宽cm/高cm；重量 → 重量kg；承重 → 承重kg。可旋转填"是/否"。缺名称或长宽高的行自动跳过。

### 4.4 执行配载

点击 **「🧊 一键智能配载」**：
- 已读取/导入路线时：按站点顺序装车（先到站靠门），货品优先分配给路线包含其站点的车辆
- 无路线时：按纯容量策略多车分配
- 完成后 toast 汇总：装入件数/用车数/温层拒装数/未装数

### 4.5 结果解读

**KPI 指标行**：
- 已装货品：`55/60` 表示 60 件中装入 55 件
- 体积利用率：装载体积占厢容百分比（多车汇总）
- 重量利用率：实际载重占额定载重百分比
- 装载层数：堆叠层数
- 用车数：`2/3` 表示 3 辆车用了 2 辆
- 未装货品：所有车都装不下的件数，红色警示框会列出明细与建议

**车辆切换卡片**：每辆车的 chip 显示装载件数、体积率；带 `🗺️按站装车` 标记表示该启用了站点顺序装载；带 `🚫温层拒装N` 表示该车温区拒绝了 N 件货品。

**3D 视图操作**：
- 左键拖拽旋转视角，滚轮缩放，右键平移
- **点击任意货品**：弹出该件详情（名称/尺寸/重量/温层/站点/坐标）
- 橙色半透明面 = **车门端**（x=L 端），卸货方向参照
- 蓝色线框 = 车厢边界；非常温货品按温层色渲染（冷冻蓝/冷藏青），常温货品按货品颜色渲染

**装载清单视图**：每件货品的编号、尺寸、坐标（X 长 / Y 高 / Z 宽方向）、重量。

### 4.6 装卸顺序与站点联动

「🔢 装卸顺序」标签页分两栏：

- **装车顺序**（蓝）：从车厢最深处到车门——后到站的货先装（放里面），先到站的货最后装（靠门）
- **卸货顺序**（橙）：后装先卸 + 上层先卸；有路线联动时按站点访问顺序卸货，站点内仍遵循物理顺序（先卸无阻挡的）

页面还会显示**站点装车分布报告**：每个站点的货品件数与深度百分比（深度=距车门比例，越小越先卸），以及**物理阻挡检测**——若出现"后到站货物挡住先到站货物"，会给出 ⚠️ 提示数量（理想为 0，即按站卸货无需翻箱）。

### 4.7 导出与打印

| 入口 | 产出 | 用途 |
|---|---|---|
| 📄 导出方案 | CSV（含车辆/名称/尺寸/坐标/装车序/卸货序/汇总行） | 存档、导入其他系统 |
| 🔗 联动导出 | JSON（车辆+箱位+未装清单） | 供「智能调度」模块联动 |
| 🖨️ 装卸工单 | 打印页（路线、偏载提示、装/卸序号、签字栏） | 司机随车任务单 |
| 📋 合规报告 | 打印页（各车体积率/载重/纵向横向偏载/重心高度/等级/检查项/建议） | 安全与合规存档 |

打印时允许浏览器弹出新窗口（工单页自动唤起打印对话框）。

## 5. 约束规则说明（求解器是怎么"想"的）

### 5.1 放置与旋转
- 可旋转货品尝试全部合法朝向（不可倒置件只试水平 4 向）
- 放置位置遵循 BLB 原则：优先贴地板、贴车厢深处、贴左侧
- 底面至少 50% 面积获得支撑才可放置

### 5.2 堆叠与承重链
承重 kg 字段 = 该货品顶面可承受的**总**重量。求解器会沿支撑链**向下累计传递压力**：

```
C (60kg)          ← 顶层
 └─ 压在 B 上：校验 B承重 ≥ 60
B (80kg)          ← 中层
 └─ 压在 A 上：校验 A承重 ≥ 60+80=140（传递！）
A (承重 120kg)    ← 底层
```

若 A 只能扛 120kg，C 会被自动拦截或换位——即使 B 自身承重富余。留空承重 = 不限制。**典型用法**：冰箱顶部可放轻型货（承重填 200~300），玻璃面板件承重填 0 或很小值（禁止堆压）。

### 5.3 温层隔离
货品温层必须落在车厢勾选的温区内，否则该车拒装。常温车装冷藏货、冷藏车装冷冻货都会被拒绝，未装清单会注明原因。

### 5.4 多车分配
两阶段：① 站点感知——有路线时，货品优先分配给路线包含其站点的车辆；② 容量贪心——剩余货品按温层匹配依次填入有空余的车。任何车辆都装不下的货品进入"未装清单"，建议增车或改车型。

### 5.5 站点顺序装车（stop-aware）
车门在 x=L 端。后到站的货装车厢深处（低 x），先到站的货靠门（高 x）。这样沿途卸货无需整体翻箱。

## 6. 常见问题 FAQ

**Q1：为什么有的货品装不上？**
按优先级排查：① 载重超限（换大车或减货）；② 空间不足（尺寸超厢或碎片化，看是否可旋转）；③ 温层不符（芯片上有 🚫温层拒装标记）；④ 承重链超限（上方货太重，调低堆叠或改承重设置）；⑤ 超长件超出车厢对角线（需拆分或专用车）。

**Q2：承重填多少合适？**
冰箱/洗衣机等大家电顶面承重参考厂家标准，一般 100~300kg；纸箱货 30~80kg；注明"不可堆叠"的货填 0。留空=不限堆压（仅建议对托盘/木架件留空）。

**Q3：单文件版需要联网吗？**
配载求解、路线导入、CSV/JSON 导出、工单与合规报告打印均离线可用；单文件版的 **3D 视图与 Excel 导入**需联网加载第三方组件（Three.js / SheetJS CDN），无网络时降级为装载清单 + 装卸顺序视图（信息完整，仅无 3D 渲染）。源码部署版（static/ 目录 + 本地 lib）则完全离线。

**Q4：站点名必须和路线里的一致吗？**
是。站点感知按名称精确匹配；不一致的站点货品按无站点处理（仍会被装载，但不享受按站顺序装车，会分到"未知站点"组）。

**Q5：为什么卸货顺序是"后装先卸"？**
堆叠物理约束：上层货必须先卸才能取到下层货。装车顺序本身就是为卸货倒序设计的。

**Q6：修改货物后要重新配载吗？**
是。所有编辑（尺寸/数量/承重/站点/车队）都需重新点「一键智能配载」生效。页面数据仅存于浏览器内存，重要方案请用导出功能保存。

**Q7：两个页面（智能调度/货品配载）怎么联动？**
方式一：在智能调度页求解后回到本页点「📡 读取调度结果」（同浏览器自动共享）；方式二：调度页导出路线 JSON，本页「🗺️ 导入配送路线」导入。联动后配载自动按站点顺序装车。
